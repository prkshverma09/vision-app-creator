# Dataset rights records

A rights record is a human approval gate, not proof generated by this repository. No authorization is currently supplied. Only an authorized operator may create records from `rights-record.template.json`; never infer an approver, permitted use, redistribution right, or expiry.

Each JSON record requires `id`, `approved_by`, `approved_at`, `permitted_uses`, `redistribution`, and `source_ids`. A manifest's `source_id` must be covered by its referenced record. Record only the minimum non-secret audit information. Store contracts or sensitive evidence in the operator's approved system, not this repository; this record may reference that system in `notes` if policy permits.

If authorization is absent, expired, ambiguous, or excludes development/evaluation, do not add the data. Restricted footage must remain outside version control regardless of redistribution policy.
